The mental model

Small pieces. A shared shape.

The graph, explained ↗
01 / Identity

An entity is a thing.

A stable entity.eid identifies it. Components describe it without changing its identity.

02 / Vocabulary

Components give it meaning.

A vocabulary declares component names and property types. One entity can carry several components.

03 / Transactions

Bundles carry the change.

A bundle is an entity’s components as JSON. Send a batch of patches: all writes commit, or none do.

Your machine. Your graph.

Run locally.
Let agents in.

The CLI opens a local graph from its config. Start its HTTP server when you need a web interface or an MCP endpoint. Local commands don’t require a running server.

The @yaks/mcp plugin exposes /mcp to agents. Choose the authentication policy for any graph you expose beyond your machine.

Host configuration ↗
A local graphShell
# Create your graph and config
yak init Ada

# Open it, run a command, exit
yak --config ~/.yak/yak.json task list

# Serve its configured HTTP routes
yak serve --config ~/.yak/yak.json

# Or select a remote MCP server
yak --host yaks.app app_list
