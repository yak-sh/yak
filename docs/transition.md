# The transition: fleet components → package vocabularies

The fleet server is being dismantled, not preserved. The `@yaks/*` packages are
designed for the use-case — tasks, projects, personas, dreaming, sessions, mail,
memory, wake, canvas, docs, hooks — and `src/vocab/manifests/*.json` is read
here only as a CHECKLIST of functionality that must stay expressible. Where the
fleet's shape was bad, the package does not copy it.

Jeff, 2026-09-19, verbatim (C#9faadb22f2 on D-37573):

> we're not trying to put the fleet server comps anywhere, we're tying to make
> the packages work properly for the use-case. well-designed and not burdened by
> the fleet-servers bad decisions. … just build the packages and plugins, export
> all the fleet data and just import it into a new plugin-powered db and there's
> no need to "migrate" it live. … all the code you're writing to adapt it is all
> going to get deleted. it's one-time use.

So there is no live migration. `src/` keeps its own vocabulary until it is
deleted whole at cutover (T-37584); the transition is a one-time export of the
fleet db into bundles and an import into a db `yak serve` opens with the
plugins. **This table is that script's spec**: one row per fleet component,
naming the package component its rows become, or saying why nothing takes them.

`bin/transition_test.ts` holds the table to the files: every manifest component
appears exactly once, and every package component named here exists.

## What a well-designed shape changed

- **A word has one home.** All 34 package vocabularies load together with no
  collision. Where the fleet and a package spelled one word two ways, the
  package's meaning stands and the fleet's rows are converted: its
  `worktree{cwd, branch, base_revision}` becomes @yaks/git's
  `worktree{repository, path, branch, head}`, and its platform roster
  `member{space, person, role}` becomes @yaks/member's `member` for belonging
  plus `grant{app, person, access}` for the ladder — belonging and authority are
  two facts, not one enum.
- **Every column says what it means.** Each entry carries a description, refs
  carry `death`, server-written columns carry `stamped`, prose carries `search`,
  so the vocabulary teaches without a second document.
- **A server's bookkeeping is not a word.** `setting` and `signal` were the
  fleet server's config table and timer bus; a plugin reads its own config and
  @yaks/wake already says a reminder and its firing.
- **A call is a call.** The fleet grew a component per tool name — `bash`,
  `fetch`, `patch`, `apply`, `graph_query`, `headers`, `opaque`, `response`,
  `stderr`, `timeout`, `task_context` — and a `tool_use{name, detail}` block
  beside them. @yaks/tools says `tool{name}`, `call{to, args}` and
  `result{call, ms}`; those twelve become rows of `call`, and the package needs
  no change at all for the transition.
