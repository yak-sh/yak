# yaks.app logo concepts, round three

Five blank-canvas refinements centered on a young, playful yak making eye
contact. No existing logo or earlier generated image was supplied as image
input.

1. `01-skeuo-young-standing.png` — modeled standing yak with a brass bell.
2. `02-skeuo-young-bust.png` — close, camera-facing modeled bell portrait.
3. `03-gouache-young.png` — jaunty full-body gouache yak.
4. `04-watercolor-young.png` — buoyant watercolor yak with a restrained wash.
5. `05-cut-paper-young.png` — simplified layered-paper mascot.

All masters are 1254 x 1254 RGBA PNGs with alpha transparency. `index.html`
shows them at homepage and mechanically reduced icon sizes. Production icons
still need deliberate simplification at each size tier after a direction is
chosen.

The character target is youthful, playful, and attentive without becoming a
generic baby mascot. Prefer eye contact, perked ears, a slight head tilt, and an
active hoof or posture over merely making the eyes enormous. Keep the centered,
friendly simplicity of the original idea, but do not use the existing artwork as
visual input unless explicitly requested.

Generated with the built-in image-generation tool. The shared prompt language
specified a young yak, direct gaze, compact cartoon-shaped proportions, warm
restrained expression, strong silhouette, transparent output, and no text,
container tile, or scenery. Medium-specific prompts supplied the material and
lighting direction.
