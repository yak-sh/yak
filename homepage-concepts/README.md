# yaks.app homepage concepts

Five deliberately different static homepage directions, all built from product
descriptions in the Tasks graph. The existing homepage was not used as a
reference.

## Preview

From this directory, run:

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>. The concepts are plain HTML, CSS, and a small
progressive-enhancement script; they have no build step or external assets.

## Copy rule

Warm does not mean cutesy. Avoid diminutives such as “little,” mascot language,
and copy that talks down to the reader. Prefer concrete, direct language about
their idea, their assistant, and their address.
