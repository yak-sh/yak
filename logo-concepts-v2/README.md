# yaks.app logo concepts, round two

Seven blank-canvas yak directions. No existing logo or earlier generated image
was supplied as image input.

1. `01-skeuo-standing.png` — dimensional standing yak with a meadow tag.
2. `02-skeuo-bell-bust.png` — compact modeled bust with a brass bell.
3. `03-skeuo-resting.png` — quiet, sculptural resting yak.
4. `04-skeuo-stride.png` — animated modeled yak with a woven blue scarf.
5. `05-cut-paper-stride.png` — layered torn-paper alpine scene.
6. `06-gouache-profile.png` — windward, hand-painted profile.
7. `07-watercolor-portrait.png` — loose watercolor portrait with a sage wash.

All masters are 1254 x 1254 RGBA PNGs with genuine alpha transparency.
`index.html` compares them on light and dark grounds and mechanically scales the
masters to 64, 32, and 16 pixels as a stress test.

The final icon family should be redrawn by size tier, not blindly downsampled.
The 512 and 256 pixel versions can retain microdetail; 128 pixels should group
materials; 64 pixels should reduce fur and props; 32 pixels should strengthen
the eyes, horns, and silhouette; and 16 pixels should be a symbolic miniature.

Concept generation starts from the subject brief. Do not use an existing logo as
visual input unless the owner explicitly requests it.

Generated with the built-in image-generation tool. The prompts described an
adult yak and the intended medium, then emphasized a friendly-but-not-childish
expression, tactile materials, a clear silhouette, transparent output, and no
text, badge, or app-icon tile. The four skeuomorphic prompts additionally called
for toy-scale modeled forms, plausible fur, keratin, metal or cloth, warm studio
light, cool fill, ambient occlusion, and contact shadows.
