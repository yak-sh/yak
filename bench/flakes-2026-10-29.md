## New repair

[Run 40898516690](https://github.com/yak-sh/yak/actions/runs/40898516690) passed
13,514 behavioral tests but failed the executable effects README example
`packages/effects/README.md:531 ee78a2fe4e93` at 1.0 ms. The same README blob
`889aca8ec668baac5f3d04ec2bda4290a2c4814f` appears in the preceding failed
[run 40895356854](https://github.com/yak-sh/yak/actions/runs/40895356854). The
later commit, `685dfdfc7`, changes the site's drawing and admin presentation; it
changes neither the effects implementation nor that example.

The example built a vocabulary and graph, applied an order, ran two failed
attempts, advanced a virtual clock and checked the whole lifecycle in one timed
case. It remains a self-contained documentation example. Its executable coverage
now lives in `packages/effects/readme_test.ts`: two independently prepared
receipts each measure one attempt, checking `last()`, pending/failed state,
attempt count and reports. Setup and the preceding attempt are outside that
case. No lifecycle assertion was dropped. The narrow README and example tests
pass 21 cases with zero CPU budget overruns.

The Search registry test also failed in
[run 40609600121](https://github.com/yak-sh/yak/actions/runs/40609600121): it
waited for a table shell and immediately expected the asynchronously rendered
row. Its readiness condition now waits for the table's answered row. The
palette's separate debounce test injects a clock and advances 149 then 1 ms; it
no longer waits through a runtime timer. Both preserve their behavior
assertions.
